# Member 2 generated workspace

This is the only directory reserved for Member 2 generated build and acceptance outputs.

Run `python scripts/build_conexus_runtime.py` from the project root. The script creates:

- `conexus-source/` — disposable copy of the checksum-verified upstream Conexus source with the Member 2 patch applied and development dependencies installed.
- `conexus-runtime/` — runnable Local Host distribution with production dependencies.
- `fixtures/` — disposable collaboration and review fixtures generated by the preparation scripts.

Generated subdirectories are ignored by Git and can be deleted and rebuilt. Do not place credentials, real provider responses, personal data or long-lived production databases here. The handover archive includes only this README and its manifest, not machine-specific build output.
